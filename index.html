A VPN for networks that block VPNs

Veilway is open-source software for running your own VPN server on a censored or hostile network, for yourself or a small group. The first release, v0.1.0-alpha, installs a server and its web panel with one script or Docker, and connects from Linux, macOS, Windows and Android.

Download the apps Install a server

AlphaIt has had no outside security review. The macOS and Windows apps are built but have not been tested on a real machine yet. Expect bugs, and tell us about them.

Where it stands

Do not rely on Veilway where a failure would put you at risk. Nothing in it has been tested against deep packet inspection or active probing, and its protocol spec is a draft only the project has reviewed.

Works today

  • A server that runs WireGuard for many users over obfuscated UDP, TLS, WebSocket or a fronted HTTP path, with routing rules, quotas, and config reload without a restart. Someone who probes it without an account gets the operator's own website.
  • A web panel in English and Persian: admin sign-in with two-factor, users and devices, subscription links and QR codes, the server's inbounds, exits and routing, linking two servers, traffic history, and an admin API with tokens.
  • Desktop apps for Linux, macOS and Windows, in English and Persian. They import a subscription by link or QR code, ask plainly before anything risky, connect with one button, and show live speed, usage and the exit. A kill switch blocks traffic when the tunnel fails.
  • An Android app on the same engine, with the same screens in both languages.
  • Links between two servers, paired with codes both operators compare.

Install a server

One script installs the node, the panel or both on a Linux server, and checks every download's signature with minisign before it installs anything. Run it as root:

curl -fsSL https://raw.githubusercontent.com/veilway-project/veilway/main/scripts/veilway.sh | sudo bash

Docker images with a compose file are another option: ghcr.io/veilway-project/veilway and ghcr.io/veilway-project/veilway-panel. The getting started guide walks through both.

Downloads

The apps for Linux, macOS, Windows and Android, and the node, are on the Veilway releases page. The panel has its own releases. The install script fetches both for you.

Next

The optional Xray add-on: off by default, it runs the official Xray release beside Veilway so a server and the apps can also speak VLESS, VMess, Trojan and Shadowsocks. After that, more HTTP shapes for the fronted path, bonded connections for networks that slow down each connection, HTTP/2 on the TLS and WebSocket transports, and a mode where the server shows a real site's handshake.

What it does differently

The tunnel stays standard. The work goes into getting it through, and into one set of tools from the server to the phone.

  • WireGuard's own cryptography

    The tunnel is unchanged WireGuard, through boringtun. Veilway works around the tunnel and does not invent its own encryption.

  • Transports for where UDP is blocked

    The tunnel can travel over obfuscated UDP, TLS, WebSocket or a fronted HTTP path. Someone who probes the server without an account gets the ordinary answer of the operator's own website.

  • One engine for the server and the apps

    The server and the apps are built on the same Rust core, which is also a library for anyone who wants a WireGuard engine in their own program.

  • Enter one server, leave from another

    Two servers can be linked, so users connect to one and their traffic leaves from the other. The operators pair them with two codes and compare a fingerprint, in the panel or on the command line.

  • English and Persian from the start

    The design system and the docs are written in both, with right-to-left layout, Persian digits and Jalali dates, and so is every app built on them.
