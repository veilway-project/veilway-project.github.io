A VPN for networks that block VPNs

Veilway is open-source software for running your own VPN server on a censored or hostile network, for yourself or a small group. One project holds the Rust core, a web panel and the apps.

Read the code Read the docs

ExperimentalIt has had no outside security review and there is no release to download yet. Today it is for operators and developers who build from source.

Where it stands

Do not rely on Veilway where a failure would put you at risk. Nothing in it has been tested against deep packet inspection or active probing, and its protocol spec is a draft only the project has reviewed.

Works today

  • A server that runs WireGuard for many users over UDP and WebSocket, with routing rules, quotas, and config reload without a restart.
  • The new protocol on both ends: a control channel inside the tunnel and four transports, with a client whose TLS handshake looks like a common browser's.
  • The client's tunnel layers for Linux, Windows and macOS, with a kill switch that blocks traffic when the tunnel fails. The Windows and macOS layers have not run on a real machine yet.
  • A web panel in English and Persian: admin sign-in with two-factor, users and devices, subscription links and QR codes, the server's inbounds, exits and routing, linking two servers, traffic history, and an admin API with tokens. It has not run against a real server yet.
  • A desktop app for Linux, Windows and macOS, in English and Persian. It imports a subscription by link or QR code, asks plainly before anything risky, connects with one button, and shows live speed, usage, the exit and the provider's card. The tunnel runs in a small helper that asks for admin rights once, and the app can start at login. It has not connected on a real machine yet.
  • Links between two servers, paired with codes both operators compare.
  • The design system for the panel and the apps.

How it will install

The first release is coming. Once it is out, one script installs the server, the panel or both from a menu, checks every download's signature with minisign, and later updates and backs it up.

curl -fsSL https://raw.githubusercontent.com/veilway-project/veilway/main/scripts/veilway.sh | sudo bash

Docker images with a compose file are another option: ghcr.io/veilway-project/veilway and ghcr.io/veilway-project/veilway-panel.

What it does differently

The tunnel stays standard. The work goes into getting it through, and into one set of tools from the server to the phone.

  • WireGuard's own cryptography

    The tunnel is unchanged WireGuard, through boringtun. Veilway works around the tunnel and does not invent its own encryption.

  • Transports for where UDP is blocked

    The tunnel can travel over obfuscated UDP, TLS, WebSocket or a fronted HTTP path. Someone who probes the server without an account gets the ordinary answer of the operator's own website.

  • One engine for the server and the apps

    The server and the apps are built on the same Rust core, which is also a library for anyone who wants a WireGuard engine in their own program.

  • Enter one server, leave from another

    Two servers can be linked, so users connect to one and their traffic leaves from the other. The operators pair them with two codes and compare a fingerprint, in the panel or on the command line.

  • English and Persian from the start

    The design system and the docs are written in both, with right-to-left layout, Persian digits and Jalali dates, and so is every app built on them.
